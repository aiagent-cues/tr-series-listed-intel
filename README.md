# tr-series-listed-intel

TRシリーズ（Toyota Related / トヨタ自動車 7203）を中核とした **LLM Wiki型知識DB**。
FRシリーズ（`fr-series-listed-intel`）と対になる收集リポ。

## 含むもの
- 統合報告 / IR / HP / 組織 / 人事 / ニュースの要約
- 訓練トピック: AI開発, ESG, IFRS, 管理会計, 生産管理, SCM
- 16人体制（統括PM / リーダー / コレクタ / QA）
- GitHub Actions ソース健全性チェック

## 使い方
1. `llmwiki/index.md` から読む
2. 各ページの YAML frontmatter をRAGメタに使う
3. 数値は必ず `sources` の公式URLで確認する
