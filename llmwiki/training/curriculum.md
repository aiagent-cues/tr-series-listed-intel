# TRシリーズ 訓練カリキュラム

対象: 社内AI開発・経営企画・財務・生産・調達の中堅。
形式: LLM Wikiを教材にした読解 + 案例演習。

## 全体10時間（標準課程）

| 時間 | 単元 | Wiki |
|---|---|---|
| 0.5h | 企業地図と役割 | entities, officers |
| 1.5h | IFRSと決算読解 | ifrs, toyota-7203 |
| 1.5h | 管理会計・パスウェイ原価 | management-accounting |
| 1.5h | ESG・統合報告 | esg, integrated-report |
| 2.0h | TPSとデジタルカイゼン | production-management |
| 1.5h | SCM・グループ | scm, toyota-group |
| 1.5h | AI 4層 | ai-development, woven |

## 達成要件
- 公式数値を期間付きで説明できる
- 関税減益をESG/SCM/管理会計の3角から言える
- Woven Cityを「広報」でなくプラットフォーム戦略として説明できる
