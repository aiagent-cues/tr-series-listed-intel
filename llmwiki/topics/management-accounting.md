# 管理会計（TRシリーズ訓練トピック）

## TMCで観察できる管理会計の型
1. **パスウェイ別コスト**: ICE / HEV / PHEV / BEV / FCEV の並行投資
2. **地域別P/L**: 日本・北米・欧州・亜洲・中国
3. **バリューチェーン収益**: 車両売り切り以外（部品・金融・サービス）
4. **為替分析**: 台数・価格・原価・為替・関税
5. **資本コスト**: ウーブンシティ・電池・SDV

## FY2026の教材用解像
- 営業収益 +2.6兆円上級でも営業利益 △1.0兆円。
- 公式説明: 関税影響約1.4兆円を台数増・価格・VC収益で相殺し見通しどおりの3.8兆円。
- 自動車セグメント営業利益 2兆7,770億円（-29.5%）、金融 8,517億円。
- 営業利益率の推移: FY24 11.9% → FY25 10.0% → FY26 7.4%。

## 統合報告2025 報酬の業績連動（p112-113）
詳細: [[sources/integrated-report-2025-pass3]]
- STI: 連結営業利益70%（基準2.5兆円）+ 時価総額対TOPIX 30%。2024年度総合157%、時価総額46.8兆円。
- LTI: 3年営業利益35% + TSR 17.5% + ROE 17.5%（基準8%）+ サステナ30%。2024年度総合138%、配当込みTOPIX 213.4%。
- 構成: 固定30%前後 / STI20% / LTI50%。会長・社長は個人別査定なし。
