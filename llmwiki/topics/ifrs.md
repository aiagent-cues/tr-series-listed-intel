# IFRS（TRシリーズ訓練トピック）

TMCの連結財務は **IFRS Accounting Standards**（IASB、未留保の準拠表明）。一次テキストは Form 20-F FY2026 注記（[[sources/20f-2026-notes]] 〜 [[sources/20f-2026-notes-pass31]]）。

## 教材で押さえる要素（FY2026追記）
| 要素 | TMCでの出方 |
|---|---|
| 発行可能 / 発行済 | 2026-03-31で 50,000,000,000 / 15,794,987,460株。自己株 1,200,000,000株を 2026-06-30 消却発表（約 7.6%） |
| 単位株 | 100株=1単位。単位未満に議決権なし。単位引下げは取締役会決議 |
| FEFTA | 財務省上場リスト 2025-07-15 でコア業種指定業。改正 2025-04-04公布 / 2025-05-19施行 |
| 配当基準 | 中間 9月30日 / 期末 3月31日。取締役会決議で配当可。現金配当時効 3年 |

前パスの注記1–36・関税・4.D設備・SOX 404は [[sources/20f-2026-notes]] 〜 pass30 を正本とする。本更新で再掲しない。

## 日野側の基準差（混同禁止）
日野7205の決算短信は日本基準。ARCHION 543A のFY2027開示はIFRS。TMC 20-F（IFRS 5）と足してはならない。
