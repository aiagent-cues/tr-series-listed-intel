## Exhibit 11.1 倫理規範（施行 2025-11-01）

標題: The Code of Ethics for Directors and Operating Officers。施行日は附則第1条で **2025-11-01**（Item 16Bの既出施行日と一致）。

適用対象: 取締役および執行役員。執行役員には「執行役員に関する規程」第2条で任命される社長・副社長・フェローを含む、と本文。

| 条 | 核 |
|---|---|
| 1 目的 | 「トヨタ基本理念」「トヨタ行動指針」その他社内規程に加え、役員が経営職務で守る基本規則 |
| 2 目的 | 誠実・倫理的な行為と法令遵守 |
| 3 範囲 | 全役員 |
| 4 開示 | 適用法令に従い適切に開示 |
| 5 誠実・倫理 | 利益相反の行為・取引は会社法および社内規程に従い取締役会へ事前報告し承認を得る。当該役員は当該決議に参加できない |
| 6 財務開示 | 会長・社長・取締役・経理財務担当および同等職が、当局提出物と財務の公表情報の公正・理解容易性・適時開示に責任。開示統制と内部統制の整備も同職。財務諸表作成に関与する従業員・独立会計士を重大に誤導する行為を禁ず |
| 7 法令 | 事業国・地域の法令。内部者取引禁止を明示列挙 |
| 8 通報 | 自己または他役員の法令・倫理違反を、取締役会 / 代表取締役 / Disclosure Committee / Sustainability Meeting / これらが任命する部署・担当へ素やかに報告 |
| 8 外部窓口 | 社外法律事務所に設置した「SPEAK-UP」。匿名性を確保して調査し会社へ報告・勧告。会社は措置を取る、と本文 |
| 9 遵守責任 | 違反には法令・社内規程に従い懲戒。対象役員は懲戒決定の取締役会・Disclosure Committee・Sustainability Meeting等に参加できない |
| 10 免除 | 取締役会決議のみ。適用法令に従い開示 |
| 11 改正 | 「規程管理規則」による。所管部署が定期見直し、必要時は取締役会へ改正案 |

## Exhibit 19.1 内部者取引方針（2026-01改正）

標題: Internal Rules Relating to Insider Trading Regulations。改正表示 **January 2026**。所管表示: Secretarial Division / Disclosure Committee。

冒頭の実務指示:
- TMCまたは上場子会社の株式その他有価証券の売買前に秘書部へ相談。
- 取引証券会社へ「トヨタ自動車の役員」である旨を伝える。

背景の一次事実:
- 金商法2013年改正は2014-04施行。自ら売買しなくても、第三者の利益目的での重要事実伝達・売買推奨を禁止、と本文。
- 上場地として日本・米国・英国を列挙。TMCはロンドン証券取引所上場、と本文（FCA DTR 2.8の注記）。

### 役員向け内部規則（対象）

取締役、執行役員、エグゼクティブフェロー、シニアフェローおよびこれらに相当する者。

| 項 | 事実 |
|---|---|
| 閉鎖期間 | 各年次・四半期の会計期間末日〜決算「公表」まで売買禁止。目安は毎年4月・7月・10月・1月の1日から約5週間 |
| 事前確認 | 閉鎖期間以外でもTMCまたは上場子会社の売買は秘書部へ事前相談。秘書部は Disclosure Committee Secretariat に重要事実の有無を照会。照会履歴は回答から5年保管 |
| 重要事実がある場合 | 当該事実を知らない役員もTMC証券の売買を控える。例外: 自己株取得期間中の日次買付情報については、CFOおよび経理担当役員以外にはこの抑制を適用しない |
| 売買報告（取締役のみ） | 翌月15日までに内閣総理大臣へ報告。証券会社経由可。米ADSなど国外取引も報告対象 |
| 短期売買 | 買付後6か月以内の売却、売却後6か月以内の買付を控える（会社または株主からの利益返還請求の可能性） |
| 同居家族 | 重要事実を知る場合、同居家族の当該銘柄売買をさせない |
| 兼職 | 他上場会社役員としての当該社証券の売買は当該社規則に従う |
| 退任後 | 在任中に知った重要事実が公表されるまで売買禁止。ただし退任から1年経過すれば適用しない |
| 内部者名簿 | 役職・氏名・登録日を重要事実の種類ごとに記載。Disclosure Committee Secretariat が作成または最終更新から少なくとも5年保管。英国当局の請求があれば素やか提出 |

内部者の定義注: 職務で重要事実を得たTMCおよび子会社の役員・従業員、ならびに雇用その他契約で役務を提供し内部情報を得た者。

LSE対応: FCA Disclosure Rules and Transparency Rules §2。名簿の作成・理由・作成日、理由変更・追加・削除時の更新、5年保管、FCAへの提出、アクセス権者への義務と制裁の周知。故意の違反は制裁または公表処分の対象になり得る、と本文。

ストックオプション権利行使による取得自体は上記規則の対象外。行使後の売却は対象。

### 従業員等向け

対象は雇用・契約の有無や肩書を問わず業務に従事する者（パート・派遣・出向・転籍を含む）。海外関係会社にも所在地法に沿った同様規則を求めている、と本文。

- 重要事実を知る間の当該銘柄売買禁止、および業務上必要でない第三者への共有禁止。
- 重要事実を扱う部の部長（general manager）が取扱者を登録し、内部者名簿を Disclosure Committee Secretariat へ提出。
- 取扱者には契約締結・交渉中の相手方（取引先、提携先、弁護士、公認会計士、税理士、コンサルタント等）も含む。
- 就業規則: 遵守事項第11条第20号、懲戒解雇第75条第16号（在職中・退職後を問わず、未公表の職務上の秘密を用いた有価証券の直接・間接売買）。
- 機密管理規程第28条第2項: 金商法の内部者取引禁止。情報品質管理責任者が未公表の重要事実の関係者を登録・管理。
- 米法上、部下の内部者取引を知りながら適切な措置を取らない監督者も同一罰則の対象になり得る、と本文。
