## 15. マテリアリティ（p7-8）

## 16. カーボンニュートラル・商品（p34-36）

方針は「日野環境チャレンジ2050」。走行時削減の3本柱は電動化 / 燃料多様化 / 効率化。

- 2024-09: 小型BEVトラック「日野デュトロ Z EV」一部改良。
- 2024-10: BEVフルフラット路線バス「日野ブルーリボン Z EV」新発売。
- FC大型はTMC共同開発。2023年から関東・愛知で4台、ルートを福島まで拡大。目標航続 約600km。量産名は「日野プロフィア Z FCV」。
- 実証 2023-05〜2025-08末: 延べ稼働1,492日 / 走行約43万km / CO2削減約232,000 kg（軽油換算） / 水素約27 t。

## 17. SCM（p44-45）

継続取引先 約400社に価格協議。SSA古河工場で即日見直79件。Hino-iは約100社から2,000件超。紛争鉱物調査約300社。自家用有償受託は2025-06時点全8地域15団体。

## 18. 環境（p53-54, p63-64）

工場CO2は2013年度比 ▲60%（目標2025年 ▲30%）。廃棄物は2018比 ▲41%（目標 ▲12%）。連結2024: S1 12.4 / S2 8.4 / S3 4,835 万t。Cat11 4,374万t。水 2,741千t。廃棄物 3.59万t。環境保全コスト単体: 投資 2,370 / 費用 54,999 百万円。

## 19. 人的資本（p55-58, p65）

女性管理職 59人・2.8%（2026まで65人）。外国人管理職 7.3%（目標5%達成）。キャリア採用 40.5%。男性育休 73.6%。賀金格差 77.8%。障がい者雇用率 2.69%。通報 332件。休業度数率 0.06。

## 20. 生産・関係会社（p62, p67）

本冊グラフの車両生産（2024年度）: 日本 84,913 / 海外 36,706 / 計 121,619。グローバル販売 125,048。輸出 46,402。FY2026短信のT/バス+トヨタ向けとは定義が違う。子会社74 / 関連会社20。日野モーター セールス オーストラリアはNSWで議決権100%。工場別PPEは非掲。
