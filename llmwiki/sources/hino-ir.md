# 日野自動車IR（一次抽出）

調査時点: 2026-09-08 20:20 JST。詳細は[[sources/hino-ir-pass2]]〜[[sources/hino-ir-pass12]]。
適時開示2026頁に9月新規行なし（最新日付行は2026-03-27 15:30）。ニュース20260908-*は404。ニュース最新は20260907-004742（日野メルファ一部改良発売）。その直前行は20260903-004725（HCS、国際物流総合展2026出展）。

TMC Form 20-F Item 4.B Legal Proceedings: 2026-03-31の議決権持分 66.16%。FY2025に関連費用 281,140百万円。効力 2026-04-01 にMFTBC統合で連結除外。確認記録は[[sources/20f-2026-notes-pass32]]。

TMC Form 20-F 注36: 統合効力 2026-04-01 に日野はTMC連結除外。効力直前に日野羽村工場は TMC連結子会社 Toyota Motor Hamura, Inc. となった。影響額は評価中。確認記録は[[sources/20f-2026-notes-pass29]]。

移管後の法人公式: トヨタ自動車羽村株式会社。創立 2026-04-01 / 資本金 85億円 / TMC 100% / 従業員 5,060名（2026-04、派遣含む） / 敷地 750,000㎡ / 代表取締役社長 青木 是篤。現行車種はLC250・高機動車・1.5tトラック・ダイナ・デュトロ・デュトロZEV。2024年度生産 191,472台。詳細[[sources/hino-ir-pass8]]。

日野拠点頁の事業所は日野工場・新田工場・古河工場の3拠点。お客様テクニカルセンターは羽村テストコース内として日野頁に残る。

古河工場は 2026-06-30 に地域生物多様性増進法の自然共生サイト認定、2026-07-29 授与。大型・中型トラック製造の中核。ビオトープKOGA（池 105㎡、2024-12）。植樹約1万本（2026-08）。詳細[[sources/hino-ir-pass9]]。

HCS（日野コンピューターシステム）: 設立 1986-10-01 / 資本金 30百万円 / 従業員 559名（2026-04-01） / 年商 22,897百万円（2025年度）。Logitaは日野・三菱ふそうのコネクテッド全国50万台。詳細[[sources/hino-ir-pass9]]。

FY2025有報（提出 2025-06-24、時点 2025-03-31）の提出会社工場別帳簿。合計列は日野 18,669 / 羽村 38,237 / 新田 33,036 / 古河 41,678（百万円）。土地面積 178 / 750 / 567 / 849千㎡。設備投資 71,019。重要新設計画 40,000（日野市、2025-04〜2026-03）。川崎・中津・富山・ポルトガルは非掲。詳細[[sources/hino-ir-pass10]]。

FY2026半期報告書（提出 2025-11-14、時点 2025-09-30）。売上高 742,859 / 営業利益 38,073 / 親会社帰属中間純利益 22,502。連結有形 431,821。羽村SPA締結 2025-06-10、譲渡価額 1,500億円、新会社資本金 1円、FAはデロイトトーマツFA。カナダ和解 55百万CAD、豪州和解 87百万AUD（維州上級裁承認 2025-07-18）。ARCHION取締役会9名予定とCxO名簿。工場別PPEは本半期報に非掲。詳細[[sources/hino-ir-pass11]]。
