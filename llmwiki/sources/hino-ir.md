# 日野自動車IR（一次抽出）

調査時点: 2026-09-09 11:01 JST。詳細は[[sources/hino-ir-pass2]]〜[[sources/hino-ir-pass26]]。
適時開示2026頁に9月新規行なし（最新日付行は2026-03-27 15:30）。ニュース20260908-* / 20260909-*は404。ニュース最新は20260907-004742。

11:01追加: ARCHION Q1説明会（発表2026-08-12、PDF Last-Modified 2026-08-26）で取得原価は3,950億円（売買最終日終値387円の日野時価総額）。被取得企業は日野グループ。時価純資産（NCI除く）6,282=簿価5,121+PPA447+羽村売却益714。連結PPEはPF 6,176→Q1 5,581億円。オセアニア連結売上台数は1,913（△29%、通期見通し9,000）。詳細[[sources/hino-ir-pass26]]。

10:09追加: FY2025有報（2025-03-31、日本基準単体）の工場別帳簿は羽村38,237 / 古河41,678 / 新田33,036 / 日野工場18,669（百万円）。羽村従業員は当時3,087名。ARCHION第1期有報は持株会社単体で工場PPE非掲。統合後初Q1（IFRS）は売上6.0万台・収益5,979億円・営利2,623億円（負ののれを暫定2,332億含む）。詳細[[sources/hino-ir-pass25]]。

09:09追加: 公取委が2026-06-19に掲載した審査詳細が問題解消措置本文の一次。届出受理 2026-02-10、不命令通知 2026-02-26、主要事例6 2026-06-24。トヨタ議決権を実行後すみやかに20%未満。中型直営販売会社は2027-04-01まで近畿4府県以外を20%未満へ売却、隣接社は2028-04まで。スカニア支援はシェア10%または10年。詳細[[sources/hino-ir-pass24]]。

08:06追加: トヨタ自動車羽村の公式確定値は資本金85億円・TMC100%・従業員5,060名（派遣含む、2026-04）・敷地75万㎡・2024年度生産191,472台。現行品目はLC250・高機動車・1 1/2t・ダイナ・デュトロ・デュトロZEV。ARCHION第1回招集は吸収分割契約2025-11-27・承継2,744名・LC250製造販売の羽村移管を明記。訂正でAIB株主総会日は2025-11-04。詳細[[sources/hino-ir-pass23]]。

デュトロ Z EVは羽村製品頁の現行掲出。ふそう供給側の電気小型（車名未掲）とは別物。
FY2026有報工場別PPE・分割対価現金内訳・NZ裁判所承認確定日・PL888管轄は未掲。
