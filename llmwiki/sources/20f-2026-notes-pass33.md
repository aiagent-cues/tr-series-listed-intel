## Item 10.E 課税（印刷頁 133–137）— 譲渡益・ADS・相続

配当源泉の全体率・防衛増税切替・米日条約10%は [[sources/20f-2026-notes-pass32]] を正本とする。

### ADSの条約軽減手続

- 預託機関（Depositary）またはその代理人が、配当支払前の1通と基準日から8か月以内の1通の計2通の特別申請書を他書類とともに日本の税務当局へ提出した場合に、ADSについて軽減または免除が適用される、と本文。
- ADS保有の非居住者は、納税者区分・居住・受益所有の証明その他預託機関が求める情報を提出する必要あり、と本文。
- 事前申請を怠った場合でも、事後の所定手続で過剰源泉の還付（条約軽減）または全額還付（条約免除）を請求できる、と本文。
- 必要手続が履践されない場合、TMCは軽減税率または免除での源泉を保証する責任を負わない、と本文。

### 日本における譲渡益

- ポートフォリオ投資家である非居住者（非居住者Holder）が日本国外で普通株式またはADSを売却して得た譲渡益は、日本の所得税・法人税の対象とならないのが原則、と本文。
- Eligible U.S. Holder は、日本法上の必要提出を行えば、当該譲渡益について条約上日本の所得税・法人税を免除される、と本文。

### 日本の相続税・贈与税

- 個人が他の個人から普通株式またはADSを受遺者・相続人・受贈者として取得した場合、取得者・被相続人・贈与者のいずれも日本の居住者でなくても、累進税率の日本の相続税・贈与税が課され得る、と本文。
- 米保有者については米日遺産・贈与税条約の適用可能性を税務助言で確認せよ、と本文。税率表・閾値は本項に非掲。

### 米連邦所得税 — 配当（U.S. Holder）

- PFIC規則に服することを前提に、TMCの現行または累積E&Pから支払われる分配の総額（日本源泉控除前）は課税配当。受領時（普通株式）または預託機関受領時（ADS）に普通所得算入。
- 米法人の受取配当控除の対象外。
- 非法人U.S. HolderのTMC配当は、所定条件を満たせば軽減税率の対象となり得ると本文（適格性は各自確認）。
- 円配当の米ドル額は算入日の円/ドルレート。算入日からドル転換日までの為替差は一般に米源泉の普通損益。
- E&Pを超える分配はまず税務基準を減額し、残余は米源泉のキャピタルゲイン。
- 全株主への比例的な追加株式分配は一般に米連邦所得税の対象外。
- 外国税額控除上、当該配当は米国外源泉。保有期間が所定最短を下回る場合、またはTMC配当に関連する支払義務を負う場合、日本源泉についての外国税額控除は認められないことがある、と本文。

### 米連邦所得税 — 譲渡損益

- 売却その他の課税処分では、実現額と調整後税務基準（原則として米ドル取得原価）の差額が損益。
- PFIC規則に服することを前提に、保有1年超は長期キャピタルゲイン/ロス。非法人は長期について優遇税率の対象となり得る。キャピタルロス控除には制限あり。
- 当該損益は外国税額控除上一般に米源泉。
- 普通株式の預入およびADSとの交換、ADSの引出は、実現事由にならない、と本文。

### PFIC

判定（ルックスルー後、年次）:
- 総所得の75%以上が受動所得、または
- 資産総額の平均50%以上が受動所得を生む/生むために保有される資産。

| 項目 | 本文の事実 |
|---|---|
| FY2026（2026-03-31終了） | TMCは当該課税年度についてPFICではないと考える、と本文 |
| 将来 | 今後もPFICとならない運営を継続する意向、と本文 |
| 留保 | 年次判定であり、リース・金融を子会社で行う会社への適用は必ずしも明確でないため、当期・将来とも保証しない、と本文 |
| 該当した場合 | 一定の分配および譲渡益に追加課税と金利相当、非法人の軽減配当税率の不適用、原則として年次 Form 8621 |
| 通知 | PFICに該当すると考える課税年度があればU.S. Holderへ知らせる、と本文 |

### Non-U.S. Holder

- 米国内事業に実効的に関連（条約がある場合は米恒久的施設等に帰属）しない限り、分配に米連邦所得税・源泉は原則かからない。
- 譲渡益も同様に原則非課税。例外は (i) 米事業関連（条約がある場合はPE等帰属）、または (ii) 個人が処分年に米国内に183日以上滞在しその他条件を満たす場合。
- 法人の Non-U.S. Holder の実効関連E&Pには、状況により追加の branch profits tax（原則30%、条約で低下し得る）が課され得る、と本文。

### Backup withholding / 情報報告

- U.S. Holderの米国内での配当および売却等の対価には情報報告が適用。正確な納税者番号等を欠く場合、現行24% の backup withholding があり得る。backup withholding は追加税ではなく、適時のIRS提出で税額控除し得る。
- Non-U.S. Holderは原則として情報報告・backup withholding免除。非米地位の証明が必要な場合あり（W-8BEN / W-8BEN-E 等、米人は W-9）。
- 一定の個人U.S. Holderは外国金融資産報告の対象となり得る、と本文。
