| 株式報酬 | 年額40億円以内、割当総数年400万株以内 | 社外・監査等委員を除く取締役 |
| 監査等委員報酬 | 年額3.6億円以内 | 4名（うち社外3） |

### TCFD財務影響（p126-131）
円建ての影響額表は無い。影響は定性（大/中/小）。発生頻度は短〜2025 / 中〜2030 / 長〜2050。

参照シナリオ:
- 1.5℃: IEA、IPCC AR6 WG3など複数。乗用車はIEA NZE（BEV・PHEV中心）に加え地域性を入れた他の1.5℃も使用。
- 4℃: IPCC AR6 WG1 SSP5-8.5。

| 区分 | 主なリスク/機会 | 頻度 | 影響 |
|---|---|---|---|
| 移行・政策 | 燃費/GHG/ZEV強化による罰金・減産 | 短/中/長 | 大 |
| 移行・製品 | 電動化の売上変動 | 短/中/長 | 大 |
| 移行・製品 | パワートレーン開発費増 | — | 中 |
| 移行・製品 | 他社連携の新需要 | 中/長 | 小 |
| 移行・資源 | 電池原料逼迫と電池3R | 中/長 | 大 |
| 移行・製造 | 再エネ価格・低炭素設備・燃料転換のコスト | 長 | 小 |
| 物理・急性/慢性 | 洪水・高潮の建屋被害、供給寸断 | 短/中/長 | 小 |

環境マネジメント対象: 財務連結519社 + 連結外車両生産8社（2024年時点）。

### ブラジル・ポルトフェリス被災（p148-149）
| 項目 | 一次情報 |
|---|---|
| 日付 | 2025-09-22 |
| 主体 | Toyota do Brasil（TDB）、サンパウロ州ポルトフェリス工場（PFZ） |
| 事象 | 暴風雨で建屋倒壊。屋根全損、柱・梁の一部倒壊、生産停止。避難で人的被害は軽微 |
| 位置づけ | ブラジル唯一のエンジン工場。インダイアトゥーバ（IDT）・ソロカバ（SOR）へ供給 |
| 波及 | PFZ停止に伴いIDT・SORも停止。カローラクロス/セダン/ヤリス等 |
| 第1段階 | 下山工場でカローラHEV用ZRを増産輸出。2025-11-03にIDT・SOR再開（被災後約2カ月） |
| 第2段階 | 上郷でカローラクロス用M20、元町でシャシーを増産輸出。PFZ近傍の貸倉庫へ設備移設しNR（DI）を2026-01-26再開。ヤリス用NR（PFI）はTMMIN輸出、不足分はADM→ダイハツ滋賀 |
| 第3段階 | PFZでのエンジン製造再開（完全復興）を2027年後半と見込む |
| マザー図示 | 上郷・下山・元町・DH滋賀・TMMIN・ADM |

### 品質・情報セキュリティ・AI（p152-154）
- 2010年の一連のリコール後、当時社長の豊田が米聴聞会に出席した2月24日を「トヨタ再出発の日」。
- 品質学習館を2014年開設、毎年リニューアル。
- 情報セキュリティ: 「オールトヨタ セキュリティ ガイドライン」。第三者評価のベースは NIST SP800-82/53、ISO 27001/27002、IEC 62443。
- AI: 「AI基本方針」、開発者向け・利用者向け「AIガイドライン」。会議体「AIガバナンス推進会議」。
- GAIA（グローバルAIアクセレレーター）: 11カテゴリー（AD/ADAS、AIエージェント、モビリティ3.0、ソフトウエア効率化、カスタマー等）。
