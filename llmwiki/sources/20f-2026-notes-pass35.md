## Exhibit 19.1 会社関係者の範囲（本パス新規）

金商法上、内部者規制が及ぶのは所定の「会社関係者等」が職務等で「重要事実等」を知った場合、と本文。表の一次要約:

| 区分 | 範囲 |
|---|---|
| 会社関係者 | 上場会社（親会社・子会社を含む）の役員・従業員 |
| 会社関係者 | 発行済株式の3%以上を有する株主またはこれに類する権利者 |
| 会社関係者 | 上場会社に対し法令上の権限を有する者（許認可権限を持つ公務員等） |
| 会社関係者 | 上場会社と契約を締結した者、または締結交渉中の者（法人ならその役員・従業員を含む） |
| 会社関係者 | 上記株主・契約相手が法人の場合、同一法人に属する他の役員・従業員 |
| 元会社関係者 | 会社関係者でなくなってから1年以内の者（在任中に知った情報に限る） |
| 情報受領者 | 会社関係者または元会社関係者から直接情報を受けた者。職務上受領し法人に属するなら同一法人の他の役員・従業員も対象 |

さらに対象となる者:
- 公開買付者等の関係者（対象会社の役員・従業員を含む）および当該関係者でなくなってから6か月以内の者。
- 投資証券を発行する上場投資法人（J-REIT）とその資産運用会社の役員・従業員、ならびに当該投資証券の投資主、およびこれらの地位を失ってから1年以内の者。
- 上記から情報を受けた者。

## Exhibit 19.1 重要事実の数値基準（本文表、非網羅）

本文は「開示委員会が定める『重要事実として取り扱うべき情報の基準』も見よ」と注記。本20-F添付にその別表全文は無い。本文表の数値のみ:

| 項 | 数値基準（本文） |
|---|---|
| (1) 災害または業務に起因する損害 | 直近事業年度末純資産の3%以上と見込まれる場合 |
| (2) 業務提携（解消を含む）。例: 新規JV設立 | 3年以内に売上高が直近年度比で年10%以上増加見込み。またはJV売上×出資比率が直近年度売上の10%以上。またはJV総資産×出資比率が直近年度末純資産の30%以上 |
| (3) 株式・新株予約権・新株予約権付社債の発行 | 発行総額1億円以上見込み |
| (4) 決算情報（業績予想）。直近公表予想との比較 | (a) 売上高 増減10%以上。(b) 経常利益 増減30%以上かつ前期末純資産増減5%以上。(c) 当期純利益 増減30%以上かつ前期末純資産増減2.5%以上 |
| (5) 配当の増減 | 前期比20%以上（通期・中間とも） |
| (6) 合併、会社分割、事業の譲渡・譲受け | 当年度または翌年度売上高が直近年度比10%以上増減見込み。または総資産が増減し直近年度末純資産の30%以上。完全子会社との合併および完全子会社からの事業譲受けは除外 |
| (7) 株式分割 | 分割による増加株式数が10%以上 |
| (8) 子会社の解散 | 連結総資産が直近年度末純資産の30%以上減少見込み。または当年度および翌年度の連結売上高が直近年度比10%以上減少見込み |

バスケット条項: 上記およびAppendixに加え、上場会社の運営・事業・資産に関し、通常の投資家が知れば当該証券の売買を当然に促進または抑制する事実も広く「重要事実」とする、と本文。

米英法には金商法のような明確数値基準は無く、投資判断または市場価格への重要な影響の有無で個別判断、と本文。原則判定は金商法に従う。

公開買付け等の事実: 対象会社が公開買付けの対象となる事実、および総議決権の5%以上に相当する株式の買付けを行う公開買付けが行われる事実。公開買付者等の関係者（元関係者・情報受領者を含む）が公表前に対象会社株式を売買すれば内部者取引、と本文。

## Exhibit 19.1 公表（社内規則は金商法より厳しい）

社内規則上、「重要事実等」の公表完了は次のいずれかから **24時間** 経過した時点。

1. 代表取締役またはその委任を受けた者（広報部の部長等）が、一般紙および日本放送協会（NHK）など少なくとも2媒体に公式発表した時。
2. 上場金融商品取引所（例: 東京証券取引所）へ通知し、TDnet経由で取引所サイトに公開された時。
3. 当該事実を含む有価証券報告書・半期報告書・臨時報告書等が内閣総理大臣へ提出され、EDINETで公開された時。

24時間規則の理由: NYSEおよびLSE上場のため時差を考慮し、海外市場へ十分浸透させる。金商法より厳しい、と本文。LSEまたはNYSEが休業（休日・売買停止）の場合は24時間経過後も売買を控えるよう求め得る。

金商法上の公表時点（参考、本文）:
- 代表取締役等または委任を受けた者が少なくとも2媒体へ公式発表してから **12時間** 経過。
- 取引所へ通知し、内閣府令に従い電磁的方法（TDnet等）で公開。
- 有価証券報告書等の公衆縦覧（EDINETを含む）。

### 方針の核（FY2024 Exhibit 97.1）

- 標題: TOYOTA MOTOR CORPORATION / DODD-FRANK CLAWBACK POLICY。
- 採択主体: 取締役会。承認・採択日 **2023-11-29**。
- 根拠: NYSE Listed Company Manual のクローバック規則（SEC最終規則、Dodd-Frank法第954条）。
- 運用: Executive Compensation Meeting（本文では “the Meeting”）。用語定義は方針に添付の Appendix A（Clawback Rules）に委ねる。
- 回復対象: 証券法上の財務報告要件への重要な不遵守により会計修正再表示が必要な場合の、現任または元 Executive Officer（Covered Individuals）が受領した Erroneously Awarded Compensation。過去の誤謬が当期で重要虚偽表示になる場合も含む。
- 非執行が明示許容される場合に限り Meeting は回復しない判断可。例: **2022-11-28より前に効力を有していた日本法** に違反する場合。
- Covered Individuals の判定は Meeting。
- 対象報酬: Executive Officer 就任後に受領、当該業績期間中に Executive Officer であった、上場中、かつ修正再表示が必要となった日の直前3完了事業年度（会計年度変更の経過期間を含む）に受領したもの。方針発効前の受領は対象外。
- 金額: 修正後数値で算定し直した場合を超える部分。対象個人が納付または源泉された税金は控除しない。金額判定は Meeting。
- 回収方法（Meetingの裁量）: 直接返済の請求、他の報酬・賞与・インセンティブ・持分その他給付の減額、既付与賞の取消、これらの組合せ。
- 無過失（no-fault）。個人の帰責は問わない。
- 他の社内クローバック条項と併存するが同一報酬の二重回収は意図しない。他条項で本方針の範囲を狭めない。
- 補償禁止: 本方針で回収される額について会社または関係会社からの填補を受けられない。ただし費用の前払・償還が別途利用可能な場合はそれを禁じない。
- 解釈は Meeting。決定は最終。Clawback Rules と抵触すれば Rules が優先。Rules より広く回収しない。
- 改正・終了は取締役会。Rules が会社に適用されなくなれば本方針も効力を失う。
- 本Exhibit本文に回収実績額・対象役員名は非掲（FY2026 Item 6.F は None）。
