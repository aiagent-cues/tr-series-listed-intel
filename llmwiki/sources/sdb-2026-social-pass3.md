## バリューチェーン連携 p92-96（欄外 2026年6月更新）

GRI表示: 2-26、3-3、205-2、414-1、414-2。調達基本方針の3項: オープンドア / 相互信頼に基づく相互繁栄 / 現地化。契約に法令遵守・人権・環境を明記。

統括責任者: 調達本部 本部長・副本部長。重要案件はサステナビリティ会議のうえ取締役会が監督。

### 仕入先サステナビリティガイドライン
- 策定 2009年、改訂 2021年。一次が二次以降へ展開することを明記。
- 記載項目: コンプライアンス / 人権・労働条件 / 環境 / 責任ある資源・原材料調達 / 地域社会 / サプライチェーン展開 / ガイドライン遵守。
- 贈収賄防止ガイドライン（ビジネスパートナー用）を別途周知。
- 日本の主要サプライヤー約1,000社が賛同・署名（**2026年4月時点**）。統合報告2025の「約1,000社・2025-03」より署名時点が新しい。

### デューデリジェンス4ステップ
1. ガイドライン展開。
2. 実態調査。日本は2024年に調査内容を改訂しアンケート実施。テーマ: 会社経営 / 人権・労働条件 / 安全衛生 / 企業倫理 / 環境 / 責任あるSCM / 責任ある原材料調達。
3. リスク評価。日本は2025年にフィードバック。優先項目が不十分な先を特定。
4. リスク低減。第三者監査を一部活用。実施地: 日本・米国・欧州・タイ。**2024年実績 2社 / 2025年実績 21社**（既出ソースに無い件数）。
- 改善が見られない場合の最終手段として取引関係の見直しがあり得ると記載。
- 2024年調査展開 980社・回答 814社は統合報告2025第3パス既出。本PDFも2024年実績のまま再掲。海外類似取組み: 米・欧・タイ（2024年）。

### 救済
- サプライヤーホットライン（匿名、p143スピークアップへ相互参照）。
- **2026-04-01から一般社団法人ビジネスと人権対話救済機構（JaCER）に加盟**。UNGPs準拠の対話型救済。匿名通報可。

### 協力会（日本）
- 協豊会: 部品・資材。栄豊会: 設備・建築・物流。
- 経営者懇談会（CN・DX）。協豊会テーマ研究会（環境）と栄豊会サステナビリティ研鑻会でCFP・省エネ等のノウハウ集を共有。
- 国内サプライヤー説明会: 人権DD（2024-2025年）、CN情報発信（2021-2025年、Scope1/2/3目標算出・グリーン材マッチングのWebinar/展示）。

### 責任ある材料調達 p95（SASB TR-AU-440a.1）
方針根拠: OECD紛争地域および高リスク地域からの鉱物DDガイダンス。「責任ある鉱物調達への対応方針」。タスクフォースリーダーはサステナビリティ推進部統括部長。

潜在リスク表の材料列: コバルト / リチウム / ニッケル / 天然黒鉛 / スズ / タンタル / タングステン / 金 / 天然ゴム / マイカ。児童労働・強制労働はコバルト・スズ・タンタル・タングステン・金・天然ゴムをリスク高側に配置。

対策の時点:
- 欧州電池規則への対応。電池サプライチェーン調査で複数の製錨・鉱山を特定。
- 米国ドッド・フランク法に基づき RMI の CMRT を**2013年以降毎年**実施。
- RMAPへの参加奨励。TMNA は RMI Global Smelter Engagement Teams WG と AIAG Smelter Engagement Teams WG。
- 日本の対象子会社・サプライヤーへ説明会。2025年に社内基準でのリスク評価トライアルとフィードバック。
- 天然ゴム: GPSNR加盟 **2019年**、欧州森林破壊防止規則への対応。
- RMI EMRT 調査を **2024年〜**開始。
- RBA加盟 **2024年**。

### 販売店 p96（日本）
順序の公式表記: 1にユーザー、2にディーラー、3にメーカー。団体はトヨタ自動車販売店協会（ト販協）。
- 指定整備の全店舗総点検（自主、**2020年〜**）。ボデーペイント点検を追加（**2023年〜**）。
- 「販売店本部による業務確認活動」（**2024-04〜**）。
- 自主点検ツール・社内規程の充実サポート（**2025年〜**）。
- 下請法→中小受託取引適正法を見据えたガイドブック（**2025年**）。
- 店舗スタッフ向け映像教材を毎月配信（**2025-07〜**）。
- 人権方針の発信。技能実習生の適切な対応とハラスメントのない職場を依頼。JP-MIRAI紹介。

一次サプライヤー社数11,489は社会データ既出のため再掲しない。

## 人材育成 p115-119（欄外 2025年10月更新）

GRI表示: 3-3、404-2、404-3。三本柱（多様性・成長・貢献）は2023年から。

### 採用（単体）
- 従来: 新卒90% / キャリア10%。**2024年度キャリア採用比率 48%**（事務職・技術職）。
- リファラルとダイレクトスカウトを導入・拡大。学校推薦廃止のコース別採用。

### 教育・リソーセス
- GLOBAL21（グローバル幹部）。新任部長1年研修。対象を主任職以上の手上げへ拡大。
- 思想=トヨタフィロソフィー、技=TPS、所作=トヨタウェイ2020。
- 事務・技術: 2年目に販売店実習・工場実習。4年目以降「修行派遣」1-2年（海外現地法人、海外大学院=MBA含む、国内関連会社）。
- 技能職: EX / SX / CX 級の昇格前に他職場実習・他社研修出向。
- 海外事業体人材: TMCへOJT出向 半年〜3年。
- ソフトウェア人材組織: **2021-01** 立上げ、**2023-10** に事業・開発一体組織へ再編。

### 評価
- 2019: 年齢・資格を問わず報いる制度へ。2020: 評価・面談・職場運営アンケートを一元管理。2021: 幹部・基幹へ考課結果フィードバック開始。2022: 主任職以下へ拡大。
- 半期成果→賞与、過去1年の能力発揮→基本給。人間力は360度フィードバック。

専門スタッフ: 精神科医1（非専従18） / 心理士8 / 保健師1 / 心理師兼保健師1 / 精神保健福祉士1 / スタッブ6。必須: 人間力 OMOIYARI コミュニケーション研修（全上司と役員）。Well-being Check は入社3年目までの事技職に毎月。
