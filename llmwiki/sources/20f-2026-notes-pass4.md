## Item 5.A 営業利益ブリッジと関税（百万円、FY2026対FY2025）

営業利益 3,766.2十億円（前期比 △1,029.3十億円 / △21.5%）。自動車セグメントは前期比 △1,163.2十億円 / △29.5% で 2,777.0十億円。金融は +168.2 / +24.6% で 851.7十億円（米販金子会社の金利スワップ評価益が主因、と本文）。

| 増減要因 | 金額 |
|---|---:|
| マーケティング努力 | 710,000 |
| 原価低減努力 | △120,000 |
| 為替変動 | △195,000 |
| 費用増減および費用低減努力 | △2,030,000 |
| その他 | 605,700 |
| 計 | △1,029,300 |

分解（本文）:
- △2,030,000 の内数として **米関税 1,380,000**。
- マーケティング 710,000 の内数: 台数・ミックス 210,000、価格改定等その他 335,000。
- 製品売上原価 39,141.4十億円（+3,631.2 / +10.2%）。うち仕入先基盤強化と素材高で操業費用 +395,000。VE等設計系低減 △215,000、工場・物流低減 △60,000。素材高の対象例は鋼・貴金属・アルミ等非鉄・樹脂部品。
- 金融原価 3,079.7十億円（+131.2 / +4.5%）。財務負債残高増に伴う資金調達費用。
- 販管費 4,697.5十億円（△84.9 / △1.8%）。主因は FY2025 に計上した日野認証関連費用の反動、と本文。

関税の位置づけ: 特別損失ではなく営業費用側（費用増減行）。地域別には北米営業損益が関税を明示。日本行の本文は「費用その他および為替」で関税金額を分けない。

## 関税・認証の制度事実（Item 3 / Item 4。金額分解ではない）

Item 3: 2025年に対米輸出関税の大幅引上げ（自動車産業向けを含む）が発表され、本報告書日時点でも高関税率が継続。今後の時期・期間・範囲は予測不能、と本文。部品の輸出管理も導入済。影響は米に集中するが跨境オペレーションのため米以外にも及ぶ、と本文。

Item 4 車両安全・日本基準: 日米関税合意に基づき、米製造乗用車向けの新たな認証スキームを設置。米規制に適合する米製造乗用車は、日本国内の追加試験なしで日本販売を受け入れる、と本文。金額・発効日・対象台数の数値は本項にない。
